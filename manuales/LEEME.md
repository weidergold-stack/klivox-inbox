# Manuales de soporte

Manuales orientados al cliente, redactados a partir del código y de las páginas de cada proyecto.

- `clinify.md`: Clinify (historiaclinify.com).
- `klivox.md`: CRM Klivox, agente de IA y API de WhatsApp.
- `idei.md`: IDEI (Instituto de Entrenamiento en Implantología). Otra marca que atiende esta misma línea; trae qué es y cómo atender.
- `sonrisaspass.md`: SonrisasPass. Es para pacientes del consultorio; NO se carga en el bot de Klivox.

`api/webhook.js` carga `clinify.md`, `klivox.md` e `idei.md` y se los entrega al bot. Para corregir lo que el bot sabe, se edita el manual.
